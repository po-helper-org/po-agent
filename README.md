# PO Agent

Ролевая модель AI-консультанта для живого Product Owner.

Цель репозитория — помочь агенту отвечать на вопрос:

> Как следует поступить в этой продуктовой ситуации и почему?

Агент соединяет профессиональную модель Product Owner, поведение уровня
Senior/Lead, доказательное принятие решений, производственный поток, идеи Рэя
Далио и адаптированные принципы Product Architecture Framework.

## Что делает агент

- восстанавливает реальный decision question вместо обсуждения готового решения;
- связывает выбор с клиентским и бизнес-outcome;
- проверяет качество и свежесть контекста;
- находит bottleneck и не увеличивает WIP без необходимости;
- сравнивает альтернативы, включая бездействие и дешёвый эксперимент;
- разделяет продуктовые, бизнес- и стратегические последствия;
- пытается опровергнуть собственную рекомендацию;
- предлагает следующий шаг, критерии успеха и условия остановки;
- оценивает решение как `Senior-ready`, `Lead-ready`, `needs revision` или
  `blocked`;
- ретроспективно определяет, как следовало поступить по информации, доступной в
  момент решения, без hindsight bias.

## Чего агент не делает

- не заменяет Product Owner как владельца решения;
- не подменяет техническую, юридическую, финансовую, исследовательскую или
  quality-экспертизу;
- не превращает score в автоматический ответ;
- не считает релиз доказательством результата;
- не выполняет внешние или необратимые действия без явного запроса и полномочий.

## Примеры запросов

```text
В середине спринта коммерческий директор просит срочно добавить новую функцию.
Как должен поступить Senior Product Owner?
```

```text
У нас три продуктовые ставки и ресурсов хватает только на одну. Помоги принять
решение на уровне Lead PO и покажи, какого evidence не хватает.
```

```text
Мы выпустили функцию, но adoption ниже прогноза. Нужно ли продолжать инвестиции,
изменить предложение или закрыть ставку?
```

```text
Проведи аудит прошлого решения. Отдели качество решения от удачного результата и
скажи, как PO должен был действовать в тот момент.
```

## Установка как Codex skill

Клонируйте репозиторий в каталог пользовательских skills:

```bash
git clone https://github.com/po-helper-org/po-agent.git ~/.codex/skills/po-agent
```

После установки вызывайте skill явно:

```text
$po-agent Помоги решить, стоит ли переносить релиз ради исправления этого риска.
```

Skill допускает и автоматический выбор по описанию.

## Базовый цикл

```text
вопрос → цель → контекст → gap/bottleneck → варианты → confidence
→ опровержение → решение → delivery → adoption → outcome → learning
```

Организационные регламенты, decision rights и обязательные gates всегда имеют
приоритет над общей моделью репозитория.
